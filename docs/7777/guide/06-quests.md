### 酆都 (Hell)

有一天，孟婆分別拜訪十殿閻王。過了不久，地獄中傳出了地藏王菩薩被囚禁的消息。菩薩身邊的童子向你求救。各地的英雄們，趕快到地獄中一試身手，救出地藏王菩薩吧!

**路徑**：從絕情谷最裡面往下跳，或用 cle 傳送

**必備物品**：基本上沒有，不過最好多帶點 food 和武器以防萬一

**十殿閻王與裝備**

想辦法走到 hell，到了 hell 之後想辦法走到綠光這邊，綠光這邊是第一層。基本上有紅光、白光、綠光三個空間破裂處，在第五層可以互通。

**傳送與穿裝順序**

k 完 10 king no save eq 後，走到破裂空間 look 各個出口，找到一格「這兒方向看過去並沒有什麼特別的」，從這邊過去就到了傳送點。

```
wear 飛焰 (注意 wi fire 有可能穿到雷火)
say 天地我最大
unlock n -> open n -> n
wear 電閃 (helm) -> say 天地我最大
wear 滅神 (kill) -> say 天地我最大
wear 毀靈 (arms) -> say 天地我最大
wear 斷天 (arms) -> say 天地我最大
wear 暗黑 (dark) -> say 天地我最大
wear 化魂 -> say 天地我最大
wear 風暴 (storm) -> say 天地我最大
wear 雷火 (fire) -> say 天地我最大
最後穿雨化 (rain) -> say 天地我最大
```

每穿完一件 no save eq 後，記得都要說「天地我最大」，順序不能有誤。如果不曉得哪一層要穿哪一件 eq，可以用 `exam [eq 名稱]` 查看提示。

由於現在傳送到地牢中心可以多隻一起去，因此打了 10 kings 時應設法多帶幾隻 char 過去，這樣才能量產 plume 以減少打 10 kings 的時間。

**地藏王出現後**

地藏王出現後別急著 say yes，先看看自己身上及屬性被扣了多少，因為 10 king 的 no save eq 都會扣屬性，所以要看看身上還夠不夠裝 50 kg 的孔雀羽。如果不夠，就 wear 魔法手套增加 str，也可以 quit 再 login 恢復原本屬性。

一切就緒之後 `say yes`，就會拿到孔雀羽跟被傳送到迷橋。到了迷橋之後，想辦法走到迷橋終點，注意這邊的 mob 很強，如果沒把握 k die，就 bli 再 flee。

到達迷橋終點 `open s -> s` 就到孟婆這邊，四處找找孟婆。找到之後 `fol 孟婆 -> dispel magic 孟婆`，dm 完之後上 out/san/bar，然後 agg 0。

```
wear 孔雀羽
say 菩薩幫我
```

穿 plume 和 say 菩薩幫我一定要在同一格，但不一定要在 hell 都能得到 qmark，唯需切記不要去 clear。孟婆會 k 你，此時不要跟她硬碰硬，趕緊 flee，一直用 ear 然後 flee 或 at flee，大概打個七八下，此時再 k 孟婆，地藏王菩薩就會出現。

然後再 `say 地藏王菩薩你好`，他就會丟下金鋼圈跟一些錢，get 後 recall 就行了。

孔雀羽則要全新沒穿過的才行，因為穿過的孔雀羽就沒法叫出 mob 給你加 qmark。

**量產孟婆 eq 的方法**

- 孟婆由於不會自動攻擊，所以 dm 它是第一件事，dm 也不難，五次之內應能成功
- 打孟婆比較危險的地方在於前段 at flee 時，攻擊力一次大概 14xx，碰到 lag 可能連打二至三下
- 孟婆的血有 22xxx，以 ear 一次打 1000 的情況，大概要打十下才會開始逃命，準備五至十把以上武器（美工刀最佳）
- 碰到 full 以後，又要開始逃亡日子，打到換它逃為止，追殺時千萬不要使用 soul 等無攻擊力法術
- 試過以 wind 追殺，效果更佳，madam 根本沒有 full 的機會就可以 ko
- 交給 madam 一把 olympus 的 spoon 使她沒法使用 wind 也是個好辦法

### 魔王迷宮 (maze)

有一天，一個嬰兒失蹤了，你追到了神秘的魔王迷宮。在你面前是一座無比的迷宮。你要如何通過迷宮呢?

**路徑**：`map3 -> s6e7n`

迷宮大致來說，是指前面五層：石牆間、花園間、地道中、沼澤間和森林中。每層有幾種 mob，其中有一種會主動攻擊。一般解謎宮需要 30~60 分鐘。

**第一層 石牆間** `<時間:3min>`

石之精在西南方，出口在東北方。mob 有毒蛇藤蔓、食人藤蔓、吸血藤蔓，其中食人藤蔓會主動攻擊。

走法：
- 朝西南方向走即可發現石之精
- 隨便走，看到出口為 `es` 時，往 `s` 走到 T 字路後的 `w` 方向通往 stone
- 看到出口為 `ne` 時，`e` 走到第 1 個 T 字路往 `e` 走到第 2 個 T 字路 `n`，就通往第 2 層
- 另法：先往北，往南一格，往西南；往北至可往西，往西南

**第二層 花園間** `<時間:5min>`

花之精在東南方，出口在西北。需要先拿到爛木牌，找到謎語人。穿上爛木牌後：

```
ta man 謎語 -> talk man yes -> ta man 左問右 -> 回答正確答案（和問的結果是相反方向者）
```

mob 有捕蠅草、虎頭蜂、人面蝶。虎頭蜂會主動攻擊，身上有蜂蜜。

精石走法（多條替代路線）：
- `nes-->s....nw-->n....sw-->s....ns-->s....ne-->e....es-->s....nw-->w`
- 花-->man：`nes-->s-->n`，如至 `nsw` 或 `new` 或 `esw` 往 `w`，往西南
- 另法：第 1 個 T 字路其中一方往 stone，另一方通第 2 個 T 字路口，從第 2 個 T 字路口其中一方通往第 3 個 T 字路口，到了第 3 個 T 字路後，`w` 方向是 man，另一方是 sign

**第三層 地道中** `<時間:8~10min>`

土之精在西南，一般會出現在連續走過 3 個有三個方向出口的地方，可以用 scan 找。出口在東北。mob 有水雲鼠（會主動打人）、粉紅蟑螂、迷糊蛙。

石精走法：
- `new-->w....ns-->s....ns-->s....es-->s`
- 另法：沿路走，在 T 字路作記號，到了第 4 個 T 字路，`w` 方向為 stone（經過 1 個 T 字路），另一方則往第 5 和第 6 個 T 字路，在第 6 個 T 字路其中一方往出口

土-->水出口：`nsw-->s` 或 `new-->n`，如至 `ew` 往 `e`，往東到底，往北到底，往西到底

**第四層 沼澤間** `<時間:3m>`

走到有 `[出口: 北 東 南 西]` 這一格，其中一個方向是出口，一個是單行道會回到這裡，一個是回到第三層。mob 有水棲甲蟲、酒香蛇、刺蝟草（很兇，記得加聖光及聖佑術）。

精石走法：
- 先往北再往東，再往南，往北，往東至 `nesw` 處
- `nesw` 處隨便挑個方向，共有多種路線變體
- 另法：走到十字路，除了原來的路外，出口為 `ns` 的通往 stone，出口為 `we` 的通出口

水-->樹：`ew-->e`，往北，往東，往南，往東到底，往北

**第五層 森林中** `<時間:5m>`

樹之精在北方，出口在西南。mob 有飛天松鼠、背刺厥（會主動打人）、貓臉香菇、破碎樹。

精石走法：
- 北到底，往西，往北，往東北，至 `sw-->w`，`nes-->n`
- 另法：一直往 `n` 走，不能 `n` 就 `e` 或 `w` 然後 `n`，重複下去直到找到 stone
- 出口則往 `w` 到沒路時 `s`，然後 `w`，這層迴圈最多，注意不要原地繞

**交石順序與傳送**

走到第五層出口時（敘述有 stone 的地方），依序：

```
gi flower stone
gi tree stone
gi water stone
gi soil stone
gi stone stone
```

這時會傳送到風之草原/冰之高地/火之谷/沙之丘之一。先打精靈拿物品，再找到敘述 `[hole]` 的地方，於正確時間打 `gi xxxxx hole` 後傳送到黑堡。各傳送區：

| 區域 | 物品 | 時間 |
|------|------|------|
| 沙 (sand) | 十字狀的狗屎 am 5，十字狀的葉子 pm 7 | |
| 火 (fire) | 十字狀的樹枝 pm 3，十字狀的葉子 am 4，十字狀的石頭 pm 7 | |
| 風 (wind) | 十字狀的石頭 am 1，十字狀的樹枝 pm 7，十字狀的葉子 am 9 | |
| 冰 (ice) | 十字狀的石頭 am 11 | |

打完 stone 後可集體傳送，因此可多人組團一起解此 quest。

殺善心惡魔 (good devil) 後骯髒嬰兒 (dirty baby) 會出現：

```
say 來!哥哥抱你
```

回答 yes 得到加 con 的 toy，回答 no 再殺了他可得到加 dr 的 toy。

**附加說明**

- guard 只會在原來的那格附近逃跑
- 有些方向偶爾會變，但正確出口不變
- 有些關鍵 room 出口會變，花與土比較有這種情形
- 結論是，就算有 map 還是要常去，以經驗彌補

### 睡美人

**必備物品**

- 超合金：到 A 找泉水精靈 (di) 交談「發生了什麼事」及 yes，帶到泉水處，交談「要」而取得
- 隕石：B 的四個角落取得（每到 12 點就會 reborn 一顆）
- 精靈的祝福：到 C 找精靈之王交談「精靈的祝福」、「什麼水果」，到生菜沙拉找水果後給精靈之王，再交談精靈的祝福取得
- 黃銅十字架：到金字塔黃金殿堂找（`u n e u s d`）

**解法步驟**

1. 找佛娜仙女 (Mistress Fauna)：`ta mistress 拯救公主` -> `ta mistress why`
2. 幹掉五位王子：
   - 膽小的王子：`ta princess 快滾!!`（有時要多說幾次）
   - 貪婪的王子：給 0.1m 或殺了他
   - 惡劣王子：殺
   - 聰明王子：殺
   - 英勇王子：最難殺，需要 dm 及 dark 比較好打。ten-kni 可以 dm 成功後用 ten 打，連 ten 三下後立即 recall 再回來
3. 打敗王子時會出現「你打敗了他」的訊息，若沒有則要重打
4. 找佛娜仙女 `ta 沒有對手了`
5. 找泉水精靈帶到泉水處取得超合金，給佛娜仙女取得**真理之劍**（劍不見可 ta mistress 劍遺失了）
6. 找梅莉仙女 (Mistress Merryweather)：`ta mistress 拯救公主`，給隕石
7. 找精靈之王取得精靈的祝福，給梅莉仙女取得**美德之盾**（盾不見可 ta mistress 盾弄丟了）

8. 找芙蘿拉仙女 (Mistress Florra)：`ta mistress 拯救公主` -> `ta mistress 打敗邪靈` -> `ta mistress 邪靈懼怕的東西`
9. 問其他仙女（上午時段找梅莉仙女，下午時段找佛娜仙女）得知答案是十字架
10. 找芙蘿拉仙女 `ta mistress 十字架`，給黃銅十字架，得到**神聖十字架**（可上 san，效用十次）
11. `ta mistress 準備好了`，去 k 邪靈（在一個可以往 d 的地方），k 死後取得邪靈之魂
12. `ta mistress 邪靈死了`，會得到生命之神所賜予的力量


即可登上幽靈船。

#### 船上解謎

1. 登船後在舺舨上，先清怪（守護者 guard、惡靈 evil ghost、腐屍 Death corpse）
2. 拉動桿子開啟通道：
   ```
   pull
   ```
3. 東邊木板擋路處用 `enter` 進入
4. 深入船艙找到走道盡頭的牢房，精靈長老（master）被囚禁於此

#### 救出精靈長老

```
ta master help
```

長老要求收集四件精靈裝備：
- 精靈皇冠
- 精靈手杖
- 精靈護符
- 精靈靴

收集齊全後交給長老，他會破除魔法力場。之後：

```
ta master ok
```

長老帶你前往控制室，面對幽靈船船長（leader）。

#### Boss：幽靈船船長

```
c lore leader
```

> 船長數據：Lv78，HP 12765，力量/智力/睿智/敏捷/體格 全 30，DC -1930，AC 412，HR 126，DR 144。
