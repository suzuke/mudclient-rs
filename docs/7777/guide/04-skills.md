### 互斥技能

以下技能之間互相衝突，無法同時學習：

- bare fist 拳力 ←→ soleslash 獨孤九劍
- blitz 閃電奇襲式 ←→ hunt 獵殺、swordmaster 劍訣
- heavyslice 狂暴砍 ←→ aid 準確攻擊、two weapon 雙手持劍法
- two weapon 雙手持劍法 ←→ swordmaster 劍訣、kaioken 界王拳
- swordmaster 劍訣 ←→ kamekameha 龜派氣功、reflexion 乾坤大挪移
- spellmaster 魔力加持 ←→ manamaster 法力加持 ←→ time power 子午大法
- ejinjing 易筋經 ←→ okra power 葵花寶典、evilslash 辟邪劍法

## 技能解釋與使用簡介

### 1. ABSCOND 遁逃術

```
格式: abscond
格式: abscond <direction>
```

東洋忍術中的隱遁術。可自由決定所要脫逃的方向，但是所有不可進入的地方依然不可進入，屬於強力的脫逃術。

### 2. AID 準確攻擊

準確攻擊。戰士系在正式格鬥中十分重要的技能。在戰鬥中，被你的對手躲避會使你的攻擊落空。擁有這項技能，可以降低被你的對手躲避的機會，可以說是十分實用的技能。

### 3. AGILITY 輕功

輕功，乃練功者將其體內之氣向上提昇，而使全身飄然，在戰鬥之中也較易閃過敵人的攻擊。

### 4. BACKSTAB (BS) 背刺

```
格式: bs <victim>
```

從敵人的背後使用致命的背刺，這項技能會使你的對手遭受到極為可怕的傷害，尤其學習過 BS POWER 的人，更能發揮背刺的威力，在你的對手睡著或是看不見你的時候，背刺將具有更強的殺傷力。參考 BS POWER。

### 5. BANNOFIST 般若掌

般若掌，少林寺七十二絕技之一，欲練此功須有當相的少林功夫基礎，在根基深厚的條件之下，才能發揮出此功之精髓。

### 6. BARE FIST 拳力

拳力，學會此一技能之後將會加強在戰鬥中徒手之攻擊威力。

### 7. BARTER 五鬼運財術

五鬼運財術，古代道士的專有技巧，可將藉由咒語將屍體內剩餘的靈力轉換成金錢。

### 8. BENUMB 迷香術

```
格式: benumb <obj> <direction>
```

施迷香，可以向隔壁房間施迷香(obj)。但失敗時會波及自己所在的房間。

### 9. BLITZ 閃電奇襲

閃電奇襲，學此技能可在戰鬥之中將自己的速度狂飆到極點而擊出多次連打，重創敵人。

### 10. BLOCK 左手格檔

使用左手的盾來格檔敵人的攻擊。但是具有雙手劍技能的職業在左手有武器時，也可以使用這個技能。這個技能在戰鬥中會自動使用。

### 11. BLOOMSLASH 天女散花

天女散花，為一群體性的攻擊劍法，可對面前所有敵人產生傷害。

### 12. BS POWER 加強背刺

這是一項加強背刺威力的技能，能在使用背刺傷害對手的一剎那，使破壞力巨增。

### 13. BUTTOCK 過肩摔

```
格式: buttock
```

過肩摔，一種特殊的格鬥技巧，唯戰鬥中方能使用，使用成功後將使對手行動延緩，而相對增加自己攻擊的機會。

### 14. CHANGJUNSLASH 全真劍法

全真劍法，相傳為全真教掌門丘處機所創，因其乃是依照北斗七星之方位而創，故可將人封於其中而無法動彈。

### 15. CHARGE 充電（目前無效）

```
格式: charge <character> <hp|mana|move> <amount>
```

充電，可以將自己的生命力、精神力和移動力轉移傳送到別人身上，若不輸入 amount，則將從你目前的狀態數值中任取一亂數來做。

### 16. CHARMCORPSE 操屍術

```
格式: charmcorpse <n.corpse> 或 charmcorpse corpse
```

趕屍，相傳在中國湘西一帶，道士可以利用法力，驅使屍體聽其號令。而此技能便是使屍體變成殭屍，而聽令於你。

### 17. CHAODU 超渡

```
格式: chaodu <n.corpse>
```

超渡大法。犧牲自己的內力及法力，可將屍體傳送回地藏廟。唯失敗時屍體有損傷之虞，使用時務需小心。

### 18. CHUNSHISLASH 沖虛劍法

沖虛劍法，即謙沖自牧，虛懷若谷之意，劍法保守，外人不易探得虛實，因此其劍招亦難以令人捉摸。

### 19. COMETFIST 天馬流星拳

天馬流星拳，拳術家的絕招之一。傳說中來自聖鬥士的必殺技。能爆發你體內的小宇宙在極短時間內發出極多拳招。也因此，用這個拳招將會耗損你不少的體力。

### 20. DARTING 暗器

```
格式: darting weapon <victim>
```

暗器，為中原武術之獨門絕技，可趁敵人之不備施放暗器，攻其要害，不過若敵人過於機敏則將失敗。

### 21. DAUB POISON 抹毒術

```
格式: daub <poison>
```

東洋忍術中的抹毒術。可以將毒藥塗抹在手中的武器上，但失敗時自己會中毒。經過塗抹過的武器，在戰鬥時將可對敵人造成毒害，但離開遊戲後其上的毒性將會自動消失。

### 22. DISARM 卸除武裝

```
格式: disarm <victim>
```

卸除武裝，乃是一項可將敵人手上的武器擊落的戰鬥技巧，在使用時右手也必須裝備著武器。

### 23. DODGE 閃躲

閃躲，此技能將會讓你閃躲掉對方的攻擊，使你不受任何的傷害。

### 24. DRAGONFIST 降龍十八掌

中國古老的武技。傳說中丐幫的鎮幫之寶。屬於極為剛猛的招式。共有十八式。故稱為降龍十八掌。掌力雄渾無儔。但練習的過程亦極為辛苦。

### 25. DRUNKFIST 醉拳

醉拳，相傳為清末蘇乞兒之獨門拳法，共有八式，又有人稱為醉八仙，在使出此拳法時必須在半醉的狀態之下方能發揮它最大的威力，故而引以為名。

### 26. EARTHSLICE 大地之斬

```
格式: earthslice <victim>
```

大地之斬，使用此技的勇者，將武器用力撞擊地面，造成敵人受到地震的侵害，是個相當不錯的群體攻擊技能。

### 27. EJINJING 易筋經

易筋經，傳說中，中國少林寺失傳己久的高深內功，學習此內功的呼吸吐納之法，可以脫胎換骨，加速生命力的恢復。

### 28. ENHANCED DAMAGE 加強破壞

加強破壞，學會此技巧之後，在戰鬥中將更能掌握武器的使用方法而造成更大的傷害力。

### 29. EVILSLASH 辟邪劍法

辟邪劍法，為一詭譎多變之劍法，習此劍法之人將會陰陽怪氣，不過其劍法犀利無比，在葵花寶典的魔功之下將可發揮駭人的殺傷力。

### 30. FIRESLASH 火之魔劍

火之魔劍，乃是魔法劍的一種，必須在劍招和魔法的相互配合之下才能發揮其威力，而此劍技會讓出招者發出帶著高熱火球的強烈狠劈。

### 31. FLAMESLASH 焰之魔劍

焰之魔劍，乃是魔法劍的一種，必須在劍招和魔法的相互配合之下才能發揮其威力，而此劍式一出劍身將化作一道火柱撲向敵人。

### 32. FLOWERSLASH 狂花劍法

狂花劍法，是劍術家的絕技之一，乃以迅雷不及掩耳的速度，在劍光閃閃的氣勢之下，以劍氣來傷敵，但是用這個劍招將會扣損你的移動力。而且你也必須具有相當的移動力才能施出這六招連綿齊出的劍技。

### 33. FUSISLASH 伏羲劍法

伏羲劍法，相傳為上古時代炎帝伏羲氏所創之劍法，因為時代久遠，故有許多招式都不甚完整，只留下一些基本的招式。

### 34. GANKITAMA 元氣玉

元氣玉，可將天地之間所有生命力聚集在自己的身上，而向敵人發出致命的一擊，唯其威力將視個人之內力修為而有所不同。

### 35. GIRLSLASH 玉女劍法

玉女劍法，此劍法必須由情投意合之男女二人同時出招方可見其威力，在單有一人的情況下是無法使出此招的。

### 36. GUNNER 鎗法

鎗法，為一用鎗者之無上心法，鎗法熟練者將可發揮鎗枝的最大威力，且可百步穿揚，直接命中敵人要害。

### 37. HANDSFIST 大慈大悲千手式

大慈大悲千手式，相傳為少林寺之空相大師所創，為一少林寺之上乘武學其威力雖然不比大力金剛指，可也一般人能練得起來的。

### 38. HANGING 絞殺

```
格式: hanging <victim>
```

絞殺，在叢林野戰中，士兵中常常會躲在暗處，乘敵人不注意之際，給予敵人致命的一擊。這就是可怕的絞殺。也是軍人必受的基本訓練之一，通常乘敵人「不備」之時，使用出來會有更不同的效果。

### 39. HEAVYSLICE 狂暴砍

狂暴砍，在戰鬥中，你的對手隨時可能以武器或是盾牌來阻擋你的攻擊，但是如果你學會了這項技能。將會使你的對手，因為承受不了你巨大的力量。而失去了抵擋的能力。

### 40. HIDE 藏匿

```
格式: hide
```

藏匿，此技能將可使你善於利用地形及地物作掩蔽，而使一般人看不見你，也無法查覺到你存在。

### 41. HUNT 獵殺

```
格式: hunt <victim>  設定獵殺對象
      hunt           解除獵殺
```

可怕的獵殺技能，使用此技可以在對方脫逃之時，馬上追趕過去，正是斬草除根。當被你獵殺的敵人走到你所在的房間之間，你亦會主動的開啟戰鬥，並且先行出手。

### 42. ICTUS 六脈神劍

```
格式: ictus
格式: ictus <victim>
```

六脈神劍，神州南方大理段家之絕世武功，集全身內力於雙手指尖，隔空對敵人產生傷害。此外為避免阻礙內力的運行，出招時必須卸除雙手上的所有防具，此招內力耗損頗大；攻擊威力依擊中次數遞增，但命中率將遞減。

### 43. KAMEKAMEHA 龜派氣功

龜派氣功，為武天老師的得意技之一，發功時將全身之氣集於雙掌之中，再一股作氣向敵人打去，內力愈強則威力愈大。

### 44. KAIOKEN 界王拳

界王拳，可將自己的速度及力量在短時間內爆發到極限，以發揮驚人的傷害力，唯其增益之多寡將隨內力之不同而有所改變。

### 45. KINGONFINGER 大力金剛指

大力金剛指，少林七十二絕技之一，必須有少林基本功的基礎才有可能練成，不過一般的少林弟子也是與此絕技無緣，只有極少數的人才能練成，一旦練成其威力將無與倫比。

### 46. LIFESLASH 奪命魔劍

奪命魔劍，乃是魔法劍的一種，必須在劍招和魔法的相互配合之下才能發揮其威力，劍體將在魔力的驅使之下變成一把嗜血的武器，吸取中劍者的生命力。

### 47. LOHANFIST 羅漢拳

羅漢拳，拳法家的基本武功，是少林一派的拳法，使得不使用任何武器的拳法家，仍然可以具有高度的傷害力。

### 48. MAKESCROLL 煉符咒

```
格式: makescroll <法術名稱>
```

畫符術，這一個失傳已久的茅山術，源自於中國古代道士，可以將所學的法術藉由畫符術，記錄於符咒之上。你可以使用 `recite` 這個指令來使用符咒。

### 49. MANAMASTER 法力加持

法力加持，藉由宗教上的信仰和神的力量，將本身的法力提昇，天神也會因為信仰者的忠誠而在宗教奉獻時提昇奉獻者之精神力。

### 50. NUCLEARSLASH 核變魔劍

核變魔劍，乃是魔法劍的一種，必須在劍招和魔法的相互配合之下才能發揮其威力，使用此技將會觸發核反應而引起威力強大的核爆。

### 51. OKRA POWER 葵花寶典

葵花寶典，相傳為一宮中宦官所創之絕世魔功，其後為少林方丈紅葉禪師所得，不過由於是魔功故禪師並未練成，但後又被華山弟子岳肅及蔡子峰偷學，而演變成為氣宗及劍宗兩派，學此魔功必須先泯滅人性，方能魔功大成。

### 52. OUTDO WAVER 凌波微步

凌波微步，為逍遙派之獨門輕功，練此功者不但身輕如燕而且將可在戰鬥之中快速的改變身法，令敵人捉摸不定。可以閃躲過怪物的特殊攻擊。

### 53. PARRY 格擋

格擋，學得此技能後，將可在戰鬥之中以武器化解掉敵人的攻擊。

### 54. PEEK 窺視

窺視，這個技能會使你在看別人時，順便看看對方身上所有攜帶的物品。這個技能當你學會之後系統會在你看別人的時候，就自動將別人身上的東西都顯示出來。

### 55. PIERCY 剌瞎

```
格式: piercy <victim>
```

刺割，此技能讓你能在戰鬥中以手中可行刺之武器刺向敵的雙眼而照成敵人的失明。

### 56. PLOWSLASH 天罡北斗陣

天罡北斗陣法，七名熟悉此劍陣的人將可組成的此一強勢劍陣，只要七人合作無間使可發揮強大的威力。

### 57. PRETEND 偽裝術

```
格式: pretend <victim>  偽裝成 victim
      pretend            解除偽裝
```

偽裝術，當你使用偽裝術之後，別人將無法分辨你和被你偽裝的對象，可以用來欺敵。

### 58. QUINTAIN 刺槍術

```
格式: quintain
```

刺槍術，為一特有的格鬥技巧，只能在戰鬥中使用，無法引發戰鬥。

### 59. REFLEXION 乾坤大挪移

乾坤大挪移，傳說中來自波斯古國的武功心法。可以利用巧妙的手法，將對手的的攻擊，反加諸於對手的身上。是種「以彼之道，還諸彼之身」的神秘功夫。

### 60. RESCUE 解救

```
格式: rescue <victim>
```

解救，將 victim 所受的所有攻擊都轉成為自己來承受，是一項燃燒自己照亮別人的技能。

### 61. SADFIST 黯然消魂掌

黯然消魂掌，這套掌法是一套發揮人類潛能的掌法。為一中原武術，共有十七式。當你的 HP 大於 200 時，即可使用，每次扣除 200 點 HP。這套掌法的特性是當你的生命力愈低時，使用出來的威力愈大。乃是神雕大俠楊過所創的招式。意即心情愈沉重，掌力愈強之意。

### 62. SAULINFIST 少林長拳

少林長拳，為少林寺之入門拳法，也是眾多拳法之基本拳法，威力雖不強卻也相當重要。

### 63. SCAN 搜查

這個冒險者專屬的技能，可以用來掃描你四周的敵人，但僅限於一個房間的距離。建議你在危險的區域，在移動前，先用 scan 來調查四周的情況。參考: SPY

### 64. SECOND ATTACK / THIRD ATTACK 多段攻擊

多段攻擊，學過此技能之後將會讓人在戰鬥中更能利用時機，而給予敵人更多次的打擊。

### 65. SHADOWSLASH 虛影劍法

虛影劍法，利用快速的劍式來擾亂對手的視覺，而攻其不備，有較高的命中率，但是威力並不大。

### 66. SHANYANSLASH 玄陽劍法

玄陽劍法，玄陽者黑火也，即此劍法之精髓，劍行如黑色火焰般之奇巧詭譎，讓人捉摸不定。

### 67. SHOOT 射擊

```
格式: SHOOT <victim>
```

射擊，當你使用射擊這個技能的時候，你的右手必須拿著射擊用的武器，而且武器必須搭載著彈藥或是箭。射擊和你自身的 dr 無關。強度是決定在射擊武器的威力。這是槍手強大的技能之一。參考: LOADMISSILE、UNLOADMISSILE

### 68. SNEAK 潛行

```
格式: SNEAK
```

潛行，此技巧讓你在進出房間時能無聲無息而不被一般人所發覺，趁敵人不備而予以痛擊。

### 69. SOLESLASH 獨孤九劍

獨孤九劍，乃劍魔——獨孤求敗——所創之超凡劍技，獨孤九劍，有進無退，招招都是進攻，故敵人不得不守，出招者當然無須顧及防守。

### 70. SOULSLASH 魂竊魔劍

魂竊魔劍，乃是魔法劍的一種，必須在劍招和魔法的相互配合之下才能發揮其威力，使用此招將會讓手中的劍成為一把會吸取中劍者精力的武器。

### 71. SPELLMASTER 魔力加持

魔力加持，此技能乃為魔法師在施用多次魔法之後所領悟到的，習得此技之後魔法的威力將更加強大，且花費較少之精神力。

### 72. SPY 偵查

```
格式: SPY
```

這個技能可以用來偵查你四周的玩家或者是 mob。和 SCAN 不同的是，其距離長達三個房間，可以更清楚的了解四周的環境。

### 73. STEAL 偷竊

```
格式: STEAL coins <victim>
格式: STEAL <object> <victim>
```

偷竊，讓你能在別人不注意時，竊取他身上的東西或是金錢，不過如果失敗了也必須負出當相大的代價。

### 74. STUN 點穴

```
格式: stun <victim>
```

點穴，失傳己久的中國武技絕學，能以一指之力制住對手的要害，而讓對手動彈不得，使出此技能時必須空出雙手，而且也必須具有相當的內力。

### 75. SWORDMASTER 劍訣

劍訣，為用劍者最高之心法，習得此法後，方可將自身所學之劍法發揮到爐火純青之境界，而且亦將劍人合一，不容易被人擊落手中之劍。

### 76. TAIGISLASH 太極劍法

太極劍法，為武當派開山之祖——張三丰所創之劍技，取法太極故以「無極無我」為至高境界，當用劍者將太極之精神發揮至淋漓盡致之時，此劍法將展現其無窮的威力。

### 77. THROW 武器投射

```
格式: throw <victim>
```

武器投射，學得此投巧之後可將手中的「武器」向敵人丟射，所造成的傷害力，依各人的 Dr 來計算，唯投射出去的武器將會消失不見，切記！

### 78. THUNDERSLASH 雷光電劍

雷光電劍，乃是魔法劍的一種，必須在劍招和魔法的相互配合之下才能發揮其威力，此劍技一出大地雷鳴，而敵人也將受落雷所傷。

### 79. TIME POWER 子午大法

子午大法，為修道人之上乘心法，習得此心法之後，將可在正午或子夜之時吸納天地日月之精華，並化為己身之精神力。

### 80. TWO WEAPON 雙手劍

雙手劍，這個技能可以使得你具有雙手持劍的本領，且在一回合之內，左右手的武器都可以傷害敵人。

### 81. TWOYISLASH 兩儀劍法

兩儀劍法，相傳為娥嵋派所創之劍法，取兩儀生四象，四象生八卦，八卦生萬物之意，劍招綿延不絕，生生不息。

### 82. WINDSLICE 風嘯之斬

風嘯之斬，一個比美風之靈動的劍法，運用全身的力量，一次爆發六次攻擊……將會耗盡體力，但也由於體力不支，必須要延遲一段時間方能再出手。這個技能除了內力外不扣除任何點數。

### 83. WUSHANGFINGER 無相劫指

無相劫指，為少林寺之最上乘武學，其威力來自於將己身之雜念完全摒除，心眼頓開，便可將自身之全力擊向敵人最弱之處。

## 魔法解釋與使用簡介

### 1. ARMOR 神靈呼喚

```
格式: cast armor <character>
記憶量: 20
```

神靈呼喚，施用此術將獲得天神之庇祐而增強防禦力 20 點。

### 2. BARRIER 魔法結界

```
格式: cast barrier <victim>
記憶量: 20
```

魔法結界，此一法術可以在被施法者身旁形成一魔法結界，而此一魔法結界一旦張開將可有機率性地替被施法者擋去所有的攻擊性法術。

### 3. BLESS 女神庇祐

```
格式: cast bless <character>
記憶量: 60
```

女神庇祐，此法術將會增加命中率，及一些攻擊性法術的抵抗力。

### 4. BLINDNESS 目盲術

```
格式: cast blindness <victim>
記憶量: 15
```

目盲術，此法術將可使敵人之視力暫時喪失。

### 5. BLIZZARD 雪嵐

```
格式: cast blizzard
記憶量: 700
```

雪嵐，此法術將會呼喚冰之精靈帶來一場暴風雪，將你四週的敵人都捲入這場風暴之中致使你的敵人們無法動彈而受傷。

### 6. BLOOM WEAPON 武器鍛燒術

```
格式: cast 'bloom weapon' <weapon>
記憶量: 30
```

武器鍛燒術，古代道士所獨有的法術，可加強武器的平時傷害力，唯經過鍛燒之武器，將於數小時內自動燃燒殆盡而消失。

### 7. BURNING HANDS 火臂術

```
格式: cast 'burning hands' <victim>
記憶量: 25
```

火臂術，此為一魔法師對火系魔法最初之法術，任何想對火系法術更加深入之施法者，都必須先學習此一控制火源之基本法術。

### 8. CALL LIGHTNING 雷之招喚

```
格式: cast 'call lightning'
記憶量: 60
```

雷之招喚，此法術必須要在室外，而且當時的天氣要是很差的天氣才可以，此法術一旦成功將會借助閃電之力使敵人受傷。

### 9. CANYON 土噬術

```
格式: cast canyon
記憶量: 700
```

土噬術，此一法術將會呼喚地之精靈，大地頓時之間裂開，將你的敵人吞噬，不過對於高級的敵人將不構成任何威脅。

### 10. CHARM PERSON 攝心術

```
格式: cast 'charm person' <victim>
記憶量: 80
```

攝心術，這個法術如果成功可以使得被施法的人會聽你的話。你可以 ORDER 來命令他作一些事。你必須對被你所馴服的人的行為負責，相反的如果別人砍了被你馴服的人，他一樣要接受懲罰。

### 11. CHILL TOUCH 寒霜之觸

```
格式: cast 'chill touch' <victim>
記憶量: 25
```

寒霜之觸，此一法術乃為修練冰系魔法之基礎，唯有在習得此法後方可將自身之冰系魔法更上層樓，此外中法術之人也會因為受寒氣侵蝕而力不從心。

### 12. CONFUSE 困惑術

```
格式: cast confuse <victim>
記憶量: 30
```

困惑術，此一法術將可使敵人的思路受阻，因而智力減弱。

### 13. CONGELATION 急凍術

```
格式: cast congelation <victim>
記憶量: 400
```

急凍術，此一法術會將敵人的體溫急速降至 100K 而造成傷害，並且使敵人無法自由行動。

### 14. CONTINUAL LIGHT 光球術

```
格式: cast 'continual light'
記憶量: 5
```

光球術，這個法術將會製造出一只照明用具。

### 15. CONTROL WEATHER 呼風喚雨術

```
格式: cast 'control weather' better
格式: cast 'control weather' worse
記憶量: 10
```

這個法術可以控制天氣的好壞。

### 16. CREATE FOOD 製造食物術

```
格式: cast 'create food' <string>
記憶量: 5
```

製造食物，這個法術會製造出名為 `<string>` 的食物。

### 17. CREATE SPRING 造泉術

```
格式: cast 'create spring'
記憶量: 5
```

造泉術，這個法術會製造出水源。

### 18. CREATE WATER 造水術

```
格式: cast 'create water' <drink-container>
記憶量: 5
```

造水術，這個法術將會製造出一些水裝你所指定的容器裝滿。

### 19. CROSS GLORY 十字光芒

```
格式: cast 'cross glory' <victim>
記憶量: 50
```

十字光芒。劃破自己的手臂，使鮮血流過雙臂，交叉於胸前成十字狀，口頌破邪除魔咒語，而將精神力化為攻擊敵人的強力法術。

### 20. CURE BLINDNESS 復明術

```
格式: cast 'cure blindness' <character>
記憶量: 20
```

復明術，此一法術可治療瞎了的眼睛。

### 21. CURE PARALYSIS 消麻術

```
格式: cast 'cure paralysis' <victim>
記憶量: 20
```

消麻術，此一法術可解除被施法者所受的麻痺術。

### 22. CURE POISON 療毒術

```
格式: cast 'cure poison' <character>
記憶量: 20
```

療毒術，此法術可中和你體內的毒素。

### 23. CURE LIGHT / CURE SERIOUS 輕度治療 / 強力治療

```
格式: cast 'cure light'   <character>   記憶量: 5
格式: cast 'cure serious' <character>   記憶量: 8
```

這些法術將可以對傷者作一些低程度的治療。

### 24. CURSE 詛咒術

```
格式: cast 'curse' <character>
記憶量: 10
```

詛咒術，此一法術將會減少被施法者的命中率和抵抗魔法的威力。而且會使得這個人無法被萬能的神看到，而無法將他傳送回來。

### 25. CYCLONE 氣旋術

```
格式: cast cyclone <victim>
記憶量: 60
```

氣旋術，此一法術會招來強大的氣旋，將敵人捲入而受到傷害。

### 26. DARK SPACE 闇黑結界

```
格式: cast 'dark space' <victim>
記憶量: 20
```

闇黑結界，法力高深的巫術師，具有呼喚黑闇勢力的能力。所有的法術在此一結界中將全部失效，但是由於此一勢力十分強大，難以控制，所以其力量有可能會反彈到施法者的身上。

### 27. DETECT HIDDEN 偵測藏匿術

```
格式: cast 'detect hidden'
記憶量: 50
```

這個法術可以讓被施法者去偵測到隱藏的人。

### 28. DETECT INVIS 偵測隱形術

```
格式: cast 'detect invis'
記憶量: 15
```

這個法術可以讓被施法的人有能力去看到隱形的人和物品。

### 29. DETECT MAGIC 偵測魔法術

```
格式: cast 'detect magic'

```

這個法術可以使施法者知道是否物品帶有魔法。

### 30. DETECT POISON 偵測毒性術

```
格式: cast 'detect poison' <object>
記憶量: 5
```

這個法術會去偵測到是否在食物或是飲水中有沒有毒。

### 31. DISPEL MAGIC 去除魔法術

```
格式: cast 'dispel magic' <character>
記憶量: 60
```

解咒術，這個法術將會解除被施法者身上的一些魔法影響。這個法術如果用在怪物的身上則是一種主動攻擊的法術，如果是用同伴的身上則是一種仁慈的行為。

### 32. EARTHQUAKE 地震術

```
格式: cast 'earthquake'
記憶量: 200
```

地震術，此一法術將呼喚地之精靈帶來強烈的震動，而地面之所有人亦會受到傷害。

### 33. ENCHANT WEAPON 加強武器術

```
格式: cast 'enchant weapon' <weapon>
記憶量: 180
```

這個法術可以附予一些武器一些魔法，來增加它的傷害力和命中率。這個你要施法的武器必須是沒有被施法過的。而且這個武器的陣營將和施法者目前的陣營是一樣的。

記憶量: 30

聖祐術，將會使「邪惡的生物」對你所造成的傷害，減少一定的程度。

### 67. RECHARGE ITEM 補充術

```
格式: cast 'recharge item' <object>
記憶量: 30
```

補充術，使用這個法術，可以補充一些具有法力裝置物品的法力，不過若稍一不慎則會將物品毀損。

### 68. REFRESH 補充體力術

```
格式: cast refresh <character>
記憶量: 20
```

這個法術將會恢復一個人的移動力。

### 69. REMOVE CURSE 去除詛咒術

```
格式: cast 'remove curse' <character>
記憶量: 25
```

去除詛咒術，此一法術將會除去施在一個人身上的詛咒。

### 70. REMOVE NODROP 解除磁性術

```
格式: cast 'remove nodrop' <object>
記憶量: 30
```

這個法術，可以去除一些無法丟掉的物品，也就是 nodrop 的物品。

### 71. ROCKBLAST 爆岩擊

```
格式: cast rockblast <victim>
記憶量: 40
```

爆岩擊，此法術會使地表上較堅硬之部分爆成碎片砸向的敵人。

### 72. SANCTUARY 聖光術

```
格式: cast sanctuary <character>
記憶量: 210
```

聖光術，在聖靈庇祐之下，將可使外來之所有傷害均威力減半。

### 73. SHIELD / STONE SKIN 氣盾 / 肌膚石化術

```
格式: cast shield               記憶量: 30
格式: cast 'stone skin'         記憶量: 60
```

這些法術將會降低施法者的防護等級(AC)。SHIELD 將會降低 20 點防護等級。STONE SKIN 將會降低 40 點防護等級。

### 74. SLEEP 催眠術

```
格式: cast sleep <victim>
記憶量: 40
```

催眠術，此一法術將可使得你使用的對象陷入熟睡狀態。

### 75. SOULSTEAL 勾魂術

```
格式: cast soulsteal <victim>
記憶量: 150
```

勾魂術，此法術將可吸取敵人的精神力而轉化成自己的精神力。

### 76. STAR RAIN 流星雨

```
格式: cast 'star rain' <victim>
記憶量: 150
```

流星雨，可對同一房間內的所有人施以痛擊，為對群體的攻擊性法術，所召來的流星雨大小視熟練度而會有不同，所造成的傷害次數也不同。

### 77. SUMMON 召喚術

```
格式: cast summon <character>
記憶量: 30
```

這個法術將會將你所要召喚的對像召喚至你現在的房間中，若是這召喚的對像在戰鬥中或是不和你同一個區域你都無法召喚他。而且：你在不可召喚的房間也不行。他在安全房間也不行。他在不可以 RECALL 的房間時也不行。他在私人房間(PRIVATE)時也不行。

### 78. TELEPORT 雲遊術

```
格式: cast teleport
記憶量: 50
```

這個法術將會把你從現在的房間中，任意的傳送到這個世界的任何一個地方去。但是：你在不可召喚的房間也不行。你在不可以 RECALL 的房間時也不行。

### 79. TRANSFER 傳送術

```
格式: cast transfer <number>
記憶量: 180
```

傳送術，可自由地來去於記憶中的房間，房間的記憶請查詢 `HELP RNOTE`。一般法術師只能傳送自身前往目的地，唯有學過法力加持者才可傳送整個團體內的人員。

### 80. VACUUM 魔空真刃

```
格式: cast vacuum <victim>
記憶量: 360
```

魔空真刃，藉由快速的氣旋造成局部真空，敵人將會因體內外壓力的不同而感非常痛苦。

### 81. VENTRILOQUATE 腹語術

```
格式: cast ventriloquate <speaker> <message>
記憶量: 5
```

這項法術將會將你的聲音傳送到其它的物品或是人物身上，這些物品或是人物將會說出你所打出的話。如果你所施的對像可以避免這個法術，將會顯示出某不知人物要你所指定的對象說什麼話。但是不會顯示出是誰要他說的。如果你所指定的對象無法抵擋你的法術，則會照實的說出你要他說的話。

### 82. WEAKEN 力之禁錮

```
格式: cast weaken <victim>
記憶量: 15
```

力之禁錮，此一法術成功，可使敵人之部分力量受到封印而無法使出全力。

## 技能學習指南

### 風嘯之斬 / 十字斬
- 需完成任務才能學習
- 亞瑟王在騎士堡（騎士森林是迷宮，避免向下走以躲避陷阱）
- 進入騎士堡時避開大門（薩魃 Saba 在此），從其他地方進入
- 降龍習得方式類似風嘯，學習時需穿著面具

### 凌波微步
- 向小金學習，需完成五行任務
- 五行世界需找到小金 NPC

### 陣法
- 第一陣法基礎，int 30 / wis 30 成功一次加 9 熟練度
- 組隊反而降低熟練度增幅（+6）
- 第二陣法以上：找孔明（在 sango2 東吳陣營）或周瑜學習
- 陣法是公認最難練的技能之一

### 格擋 (Block) vs 招架 (Parry)
- parry 是右手格擋，block 是左手格擋
- block 需要左手持盾/武器
- 降低 agg 或降低迴避值(dodge)不會直接觸發 block
- block 發動與否與左手裝備和 block 技能等級有關

### 射擊 (Shoot)
- 威力與 HR（攻擊命中率）密切相關
- 力量 25 時需要 HR 90 才算滿（HR 85 還不夠）
- HR 上 90 後威力有跳躍性成長
- 各武器滿 HR 射擊傷害參考：
  - 爵德珮槍 (Dreed)：~1244/發
  - FBI 配槍：~2082/發
  - 陽電子槍：~2115/發
  - 光子砲：~2852/發
  - 散彈槍 (shotgun)：~2700/發（滿HR）

### 天候控制 / 招雷 (Call Lightning)
- 需多次使用天候控制(control weather)將天氣變差
- 達到打雷天才能施放 call lightning
- 實際操作需要非常多次嘗試

### 攻擊企圖心 (Aggressive)
- `agg 0~100` 調整
- agg 高：命中率增加
- agg 低：閃躲/格擋率增加
- 學了 earthslice 後可 `agg 0` 打怪

### 投擲 (Throw) 與暗器
- 投擲傷害計算涉及 DR（防禦等級）和武器傷害力
- 暗器來源：
  - 玉蜂針：小龍女給的
  - 暗源標：黑地掉落
  - 黑色十字：黑地掉落（較易取得）
